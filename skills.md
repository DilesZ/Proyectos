# Skills

## Purpose

This file defines reusable operating skills for the product and for future work sessions. These are not platform plugins. They are repeatable execution playbooks.

## Rule

At any moment, only one revenue track should be active.

## Core Skills

## Skill: Track Selection

Goal:
- choose the best first business model for fastest first revenue

Questions:
- which track has the shortest path to cash
- which track has the lowest setup friction
- which track fits available tools and legal comfort

Output:
- one active track
- one rejected list with reasons

## Skill: Mission Breakdown

Goal:
- turn a large objective into the next 3-7 executable steps

Rules:
- each step must fit into one session
- each step must have a clear done state
- each step must include proof

Output:
- mission
- steps
- estimates
- evidence required

## Skill: First Revenue Path

Goal:
- define the shortest valid route from zero to first money

Rules:
- ignore prestige features
- prefer manual delivery if faster
- remove anything not required for the first sale

Output:
- revenue hypothesis
- first offer
- first traffic source
- first conversion action

## Skill: Session Recovery

Goal:
- resume work from a new chat, account, or PC

Protocol:
1. read `system.md`
2. read `memory.md`
3. read `agets.md`
4. read `skills.md`
5. read `checkpoints/current.md`
6. continue only from the active mission

Output:
- session summary
- immediate next action

## Skill: Checkpoint Update

Goal:
- leave the project in a resumable state

Required fields:
- current date
- active track
- active mission
- completed work
- proof collected
- blockers
- next action
