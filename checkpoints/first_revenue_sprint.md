# First Revenue Sprint

## Estado

- Activo
- Track: `Influencer IA (Fanvue)`
- Objetivo: lograr la primera facturacion real
- Definicion de exito: `1 suscriptor de pago` o `1 unlock de pago`

## Por Que Este Track

- Es el track mejor desarrollado en el repositorio actual.
- Ya existe una guia maestra y estructura operativa.
- Tiene el camino mas corto entre preparacion y primer evento de ingreso.
- Permite validar el sistema de guia interactiva con menos desarrollo adicional.

## Reglas Del Sprint

1. No abrir un segundo track hasta lograr el objetivo.
2. Cada paso debe dejar evidencia.
3. Si un paso no mueve hacia el cobro, se pospone.
4. Si un paso tarda demasiado, dividirlo en una tarea de una sola sesion.
5. Al final de cada sesion, actualizar `checkpoints/current.md`.

## Mision Activa

Lanzar una primera version operativa del negocio y provocar el primer evento de monetizacion.

## Ruta De 7 Dias

### Dia 1 - Definir Producto

Objetivo:
- dejar cerrada la identidad y propuesta base

Pasos:
1. Elegir un solo arquetipo
2. Definir nombre, bio, tono y promesa
3. Escribir la propuesta de valor publica
4. Definir el tipo de contenido de arranque

Prueba requerida:
- un documento con nombre, arquetipo, bio y promesa

Condicion de completado:
- ya no hay dudas sobre quien es el personaje ni que vende

### Dia 2 - Crear Activos Base

Objetivo:
- tener el pack minimo para abrir perfiles

Pasos:
1. Generar cara maestra
2. Crear 9-12 imagenes iniciales consistentes
3. Seleccionar foto de perfil
4. Guardar los mejores prompts usados

Prueba requerida:
- carpeta con imagenes finales y prompts guardados

Condicion de completado:
- existen suficientes activos para publicar sin improvisar

### Dia 3 - Abrir Canales

Objetivo:
- dejar operativo el embudo minimo

Pasos:
1. Crear o preparar perfil principal de trafico
2. Crear o preparar Fanvue
3. Cargar bio, imagenes y texto base
4. Configurar link principal y mensaje de bienvenida

Prueba requerida:
- capturas de perfiles configurados

Condicion de completado:
- un usuario ya puede descubrir el perfil y llegar al punto de pago

### Dia 4 - Oferta Y Conversion

Objetivo:
- dejar clara la primera oferta de cobro

Pasos:
1. Fijar precio de entrada
2. Definir oferta de bienvenida
3. Definir primer contenido de pago o unlock
4. Escribir 3 mensajes base de conversion

Prueba requerida:
- documento con pricing, oferta, CTA y textos

Condicion de completado:
- existe un mecanismo claro para pasar de visita a pago

### Dia 5 - Publicacion Inicial

Objetivo:
- lanzar el primer bloque de trafico

Pasos:
1. Publicar 3-5 piezas iniciales
2. Publicar al menos 1 pieza con CTA directo
3. Registrar formato, hora y copy
4. Medir primeras señales

Prueba requerida:
- enlaces o capturas de publicaciones

Condicion de completado:
- el embudo ya esta expuesto al mercado

### Dia 6 - Ajuste Rapido

Objetivo:
- corregir friccion antes de escalar

Pasos:
1. Revisar que perfil, CTA y oferta sean coherentes
2. Mejorar el copy que peor convierte
3. Detectar si falta mas prueba social o mas contenido
4. Preparar una segunda tanda de publicaciones

Prueba requerida:
- lista corta de cambios aplicados

Condicion de completado:
- el sistema es mas claro y mas facil de convertir

### Dia 7 - Push A Primera Facturacion

Objetivo:
- provocar el primer pago

Pasos:
1. Publicar contenido con CTA directo
2. Responder rapido a interacciones
3. Empujar mensaje de bienvenida o unlock
4. Registrar resultados
5. Si no hay pago, diagnosticar el cuello de botella principal

Prueba requerida:
- evidencia de primer pago o diagnostico del bloqueo principal

Condicion de completado:
- hay ingreso o hay un bloqueo muy concreto identificado

## KPI Del Sprint

- Dia 1 completado: identidad cerrada
- Dia 2 completado: 9-12 activos listos
- Dia 3 completado: embudo operativo
- Dia 4 completado: oferta lista
- Dia 5 completado: primeras publicaciones activas
- Dia 7 objetivo: 1 pago

## Señales De Bloqueo

- no hay claridad sobre la oferta
- no hay CTA visible
- no hay suficientes activos para publicar
- el perfil no transmite valor
- hay trafico pero no clics
- hay clics pero no pagos

## Si No Se Consigue Facturar

Diagnosticar solo uno de estos problemas:

1. trafico insuficiente
2. promesa debil
3. oferta poco atractiva
4. perfil poco creible
5. mecanismo de conversion roto

No cambiar de track hasta haber hecho una iteracion sobre ese cuello de botella.
